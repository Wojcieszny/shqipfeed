        Example

        [
  {
    "id": "market-001",
    "island": "Market",
    "english": "How much is this?",
    "albanian": "Sa kushton kjo?",
    "phonetic": "sah koos-TOHN kyoh",
    "tip": "Point at the thing.",
    "blocks": [
      { "text": "Sa kushton", "type": "power" },
      { "text": "kjo", "type": "object" }
    ],
    "verified": false
  }
]

        Prompt for any AI

        You are writing phrase cards for ShqipFeed, a beginner Albanian app for speaking with family. Return ONLY a JSON array. No markdown.

Each object must have:
- id: unique string, like "market-001"
- island: the same island name on every card in this list
- english: short everyday English
- albanian: the Albanian phrase, polite "ju" forms
- phonetic: simple English spelling of how it sounds
- tip: a short note, or ""
- blocks: a list of { "text": "...", "type": "power" | "verb" | "object" | "other" }
- verified: false
